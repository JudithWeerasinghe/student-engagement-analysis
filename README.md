# Statistical Analysis of Student Engagement in Interactive Learning Environments

This project investigates how interactive learning environments influence student engagement using statistical and machine learning techniques. The analysis is based on a Kaggle dataset and implemented using R programming.

---

##  Project Overview

Student engagement plays a critical role in academic success. This study evaluates whether interactive and modern learning environments significantly improve engagement levels and identifies the key factors that influence it.

The project applies both statistical inference and predictive modeling to understand relationships between learning environment variables and engagement outcomes.

---

##  Objectives

- Analyze the relationship between learning environment and student engagement  
- Identify key factors affecting engagement (participation, completion time, teaching method)  
- Apply statistical hypothesis testing to validate findings  
- Build predictive models to estimate engagement levels  

---

##  Dataset

- Source: Kaggle (secondary dataset)  
- Key Variables:
  - Engagement Score  
  - Participation Rate  
  - Assignment Completion Time  
  - Teaching Method  
  - Learning Environment Indicators  

---

##  Tools & Technologies

- R Programming

##  Methodology

### 1. Data Preprocessing
- Data cleaning and handling missing values  
- Feature engineering (Learning Environment Score creation)

### 2. Exploratory Data Analysis (EDA)
- Histograms, boxplots, scatter plots  
- Correlation analysis  

### 3. Statistical Analysis
- t-test  
- ANOVA  
- Spearman correlation  
- Multiple Linear Regression  

### 4. Predictive Modeling
- Multiple Linear Regression  
- Random Forest  
- Support Vector Machine (SVM)  

### 5. Model Validation
- 80/20 train-test split  
- 10-fold cross-validation  

---

##  Key Findings

- Participation Rate is the strongest positive predictor of engagement (ρ ≈ 0.99)  
- Assignment Completion Time shows a strong negative correlation (ρ ≈ -0.88)  
- Learning Environment has a moderate positive effect on engagement (ρ ≈ 0.49)  
- Teaching method (AIGC vs Traditional) is not statistically significant  

---

##  Conclusion

- Interactive learning environments improve student engagement  
- The impact is mostly indirect through participation and efficiency  
- Behavioral factors are more influential than teaching method alone
